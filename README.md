# Flores para ti

Una página de regalo: un campo de flores que nace de noche, con luciérnagas, música y la letra de la canción pintándose al ritmo de la voz.

**Verla en línea:** https://nasa-cell.github.io/las-flores-amarrilas/

## Qué tiene

- Portada con un botón; al tocarlo nacen las flores y empieza la música.
- 27 flores de colores: rosas de cuatro tipos, girasoles, tulipanes y margaritas.
- Cielo nocturno con luna, estrellas que titilan, estrellas fugaces y luciérnagas. Al tocar la pantalla salen más luciérnagas.
- Letra de «Quiero Saber» (TIMØ) al centro, palabra por palabra según se canta.
- Botones para silenciar y para ver en pantalla completa.
- Funciona en computadora y en celular.

## Cómo usarla en tu equipo

Descarga la carpeta y abre `index.html` con doble clic. No hay que instalar nada.

## Archivos

| Archivo | Para qué sirve |
| --- | --- |
| `index.html` | La página completa |
| `css/main.css` | Tallos, hojas y pasto de la animación base |
| `css/noche.css` | Cielo, luciérnagas, letra y flores nuevas |
| `flores.js` | Dibuja las flores |
| `anim.js` | Música, letra sincronizada y botones |
| `main.js` | Estrellas y luciérnagas |
| `sound/` | La canción |

## Créditos

- Animación base de tallos y hojas: tutorial «Flor amarilla» (https://youtu.be/ZSSOiJaMIk0).
- Canción: «Quiero Saber», de TIMØ. Todos los derechos son de sus autores.
